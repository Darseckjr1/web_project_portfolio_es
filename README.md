Nombre del Proyecto

- Portafolio

Descripción

Este proyecto es un portafolio web personal que reúne diferentes proyectos realizados durante mi aprendizaje en desarrollo web.

El sitio incluye enlaces a los proyectos para poder consultar cada uno de ellos.

- Tecnologías utilizadas
- HTML semántico
- CSS
- Flexbox
- CSS Grid
- Posicionamiento
- Font-face
- Normalize.css
- Prettier
- Git Bash
- GitHub

Características

- Diseño responsive para diferentes tamaños de pantalla.
- Uso de CSS Grid y Flexbox para la distribución de elementos.
- Tipografías personalizadas.
- Sección de proyectos con enlaces a cada página.
- Diseño adaptado a dispositivos móviles.

Planes de mejora

- Continuar mejorando la adaptación responsive.
- Agregar nuevos proyectos al portafolio.
